AmneziaWG 3.1

Чистый VPS: Ubuntu 24.04 / 26.04 LTS, amd64, TUN и root или sudo без пароля. Проверьте SSH, разверните сервер и назначьте его основным для новых профилей. Проверка на VPS подтверждает туннель и выход в интернет; доступность UDP из сети пользователя нужно проверить отдельно.

Добавьте VPS, которым будет управлять Củ Chi.

Keenetic → WireGuard → домашняя VM → AmneziaWG → VPS

Отдельная Ubuntu Server 24.04 / 26.04 amd64: 2 vCPU, 2 ГБ RAM, 25 ГБ диска, постоянный локальный IPv4 и SSH. Панель установит контейнер шлюза. У каждого шлюза свой профиль на VPS; подключение Keenetic сохраняется при смене VPS.

При обрыве AWG шлюз блокирует клиентский трафик. На Keenetic создайте политику только с этим WG-подключением, без резервного WAN, и отключите IPv6 у выбранного сегмента. VM и NAS оставьте в обычной политике провайдера.

Добавьте VM по локальному IP и SSH-доступу.

Уведомления на этом устройстве

На iPhone: «Поделиться» → «На экран Домой», затем откройте Củ Chi с новой иконки и подключите уведомления. На Android — разрешите уведомления в браузере. Пометка «Критично» повышает приоритет отправки, но звук и режим «Фокус» управляются устройством.

Настройки категорий общие для вашего аккаунта. История в кабинете сохраняется независимо от разрешения на push. Последние 100 событий за 90 дней.

Напомнить об обновлении профилей

Только пользователям с действующими профилями на прежнем основном сервере. Отправляйте повторно, когда это необходимо. Перед каждой отправкой список проверяется заново.

Экспериментальный режим через неофициальный wgcf. При недоступности WARP интернет через этот сервер остановится, пока вы не восстановите WARP или не выберете прямой выход. При неудачном переключении панель попытается вернуть прежний режим.

Новый сервер

Ключи и пароли хранятся зашифрованными. Для входа по паролю он должен быть разрешён в SSH на VPS.

Где взять отпечаток?

Проверьте его через доверенную консоль провайдера:

ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub -E sha256

Скопируйте только значение, начинающееся с SHA256:.

Для того же VPS сохраняется SSH-отпечаток. При смене публичного адреса AWG заново импортируйте профиль. При смене IP или домена Xray обновите подписку.

Оставьте поле пустым, чтобы сохранить текущие данные входа.

Новый SSH-ключ

Приватная часть остаётся на NAS. Публичную часть добавьте в панели провайдера при создании VPS или в ~/.ssh/authorized_keys нужного пользователя.

Удалить устройство?

Развернуть AmneziaWG

На VPS будут установлены Docker и AmneziaWG 3.1. Docker настроит маршрутизацию и публикацию UDP-порта. Используйте отдельный сервер для VPN.

Откройте этот UDP-порт в firewall провайдера. Адрес и порт фиксируются при первом деплое.
